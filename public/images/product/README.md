# Product screenshots

Captured 14 Nov 2026 from staging (coach app and athlete app) for the marketing redesign. Each shot is a WebP with a PNG fallback of the same name.

- Coach shots: laptop viewport 1440 x 900 at 2x, so 2880 x 1800.
- Athlete shots: phone viewport 390 x 844 at 2x, so 780 x 1688 (the numbers crop is 780 x 800).
- Data is demo data on staging test accounts. Names shown are demo names (coach Alex Morgan, athletes Sam Rivera and Jordan Lee); account emails were replaced in the page before capture, and staff-only links and beta prompts were hidden. Program content, loads, checks and AI replies are as the product produced them.
